How to use Excel to PDF

  1. Add one or more spreadsheet files to the drop zone below.
  2. Tap Run — each sheet is laid out as a PDF table automatically.
  3. Download the PDF (or a zip, if you added several) — one file per spreadsheet.

FAQ

Does formatting like cell colors carry over?

The tool focuses on getting values into a clean table layout; complex formatting like custom cell colors, merged cells or embedded charts may not carry over exactly.

What happens with very wide sheets?

Wide sheets are scaled to fit the page width where possible, but extremely wide tables with many columns may still wrap or shrink to stay legible.

Can I convert several spreadsheets in one go?

Yes — add multiple files and each is converted independently; you'll get a zip back if you add more than one.

Does every sheet in a workbook get converted?

Yes, every sheet in the file is included as its own section in the output PDF.
