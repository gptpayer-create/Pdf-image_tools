How to use PDF Forms

  1. Add a fillable PDF — its form fields load automatically below.
  2. Fill in each field.
  3. Tap Run to download the filled (and, if checked, flattened) PDF.

FAQ

What if no fields are detected?

The PDF likely doesn't have a real AcroForm layer — some "fillable-looking" PDFs are just images or flat text, which this tool can't detect fields in.

What does flattening do?

It bakes the entered values permanently into the page and removes the interactive form fields, so the values can't be edited afterward.
