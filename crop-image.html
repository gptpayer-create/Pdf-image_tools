How to use Crop Image

  1. Upload the image you want to crop.
  2. Enter the crop box: X and Y (top-left corner), then width and height in pixels.
  3. Tap Run to download the cropped image.

FAQ

How do I find the right pixel coordinates without a visual guide?

This version uses manual number entry rather than a drag-to-select box; opening the image in any photo viewer that shows pixel coordinates on hover can help you find the right numbers before entering them here.

What happens if my crop box goes outside the image?

The tool automatically clips the box to fit within the image's actual dimensions rather than erroring out.
