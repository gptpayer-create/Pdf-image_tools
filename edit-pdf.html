How to use Edit PDF

  1. Add a PDF and choose what to add: text, a rectangle, or a line.
  2. Set the page number, position and color.
  3. Tap Run, then re-upload the result to add another element if needed.

FAQ

Can I drag elements into place visually?

Not yet — position is set numerically in points, measured from the bottom-left of the page, matching the PDF coordinate system.

Can I add more than one element at a time?

One per run. Run the tool again on the downloaded file to keep adding text, boxes or lines.
