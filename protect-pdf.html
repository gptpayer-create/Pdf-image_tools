How to use Protect PDF

  1. Add one or more PDF files.
  2. Type the password you want to lock them with.
  3. Tap Run and download the protected file(s).

When this helps

Adding a password to a sensitive document before emailing it, so only someone with the password can open it.

FAQ

Will it really ask for a password when I open it?

Yes — this adds real encryption per the PDF specification (not a cosmetic lock screen), so any standard PDF reader will prompt for your password before showing the content.

What if I forget the password?

There's no recovery — the password isn't stored anywhere by gptpayer. Keep it somewhere safe.

Can I remove a password later?

Yes, use Unlock PDF with the same password to get an unprotected copy back.

Is this strong enough for highly sensitive documents?

RC4-40 is a legacy but widely compatible standard; for highly sensitive material, a dedicated tool with a stronger modern cipher is a better fit.

Can I protect several PDFs with the same password at once?

Yes — add multiple files and the same password is applied to each.
