How to use Resize Image

  1. Upload the image you want to resize.
  2. Enter a width or height in pixels — with 'keep aspect ratio' checked, the other side adjusts automatically.
  3. Tap Run to download the resized image.

FAQ

What happens if I uncheck 'keep aspect ratio' and enter both values?

The image stretches or squashes to fit those exact dimensions, which can distort the image if the ratio doesn't match the original.

Can I make an image bigger, not just smaller?

Yes, though enlarging beyond the original size will look soft since no new detail is created — for a sharper result when enlarging, try the Upscale tool instead.
