FAQ

Will the layout look the same as the PDF?

No — this tool extracts the text content and lays it out as plain paragraphs in Word, one page break per PDF page. Columns, tables and images from the original aren't rebuilt.

What about scanned PDFs?

If the PDF has no selectable text (it's a scan), run it through OCR PDF first, then convert the result.
