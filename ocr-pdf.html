How to use OCR PDF

  1. Add a scanned PDF.
  2. Pick the document's language.
  3. Tap Run — the model downloads once, then reads each page fully on-device.
  4. Download the .md file with the recognized text.

FAQ

Does this upload my file anywhere?

No — the OCR model runs entirely in your browser. It downloads once (a few megabytes) and then works fully offline; your PDF never leaves your device.

What languages are supported?

English, Spanish, French, German, Portuguese, Hindi, Arabic, and Simplified Chinese. Pick the one that matches your document before running.

How accurate is it?

Accuracy depends heavily on scan quality — clean, high-contrast, upright scans do best. Handwriting, skewed pages, and low-resolution scans will have more errors.
