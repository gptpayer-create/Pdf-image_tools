PDF

Cut a fixed border off every page — useful for stripping wide margins before printing booklets, removing a scanner's black edge, or tightening up a PDF that was exported with too much white space. You set the top, right, bottom and left margin in points (72pt = 1 inch), and the same crop is applied to the whole document.

How to use Crop PDF

  1. Add one or more PDFs to the drop zone below.
  2. Enter the margin to trim from each side, in points.
  3. Tap Run — the cropped PDF (or a zip, if you added several) downloads immediately.

FAQ

What unit are the margins in?

Points, the same unit PDF page sizes are measured in. 72 points equals one inch, so a 36pt margin trims about half an inch from that side.

Does this crop every page the same way?

Yes — one set of four margins is applied uniformly to every page in the file. If different pages need different crops, run the tool separately on split-out sections.

Can I crop several PDFs at once?

Yes, add multiple files and the same margins are applied to each; you'll get a zip back if you add more than one.

Will cropping affect image or text quality?

No — cropping only changes the visible page boundary. The content itself isn't re-rendered or compressed.
