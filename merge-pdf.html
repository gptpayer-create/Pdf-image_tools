How to use Merge PDF

  1. Add two or more PDF files using the drop zone below.
  2. Use the ↑ / ↓ buttons to put them in the order you want.
  3. Tap Run — your merged PDF downloads immediately.

FAQ

Is there a limit on how many PDFs I can merge?

No hard limit is enforced, but very large batches (dozens of big files) can slow down or use a lot of memory on older phones, since everything runs in your browser tab.

Will the page order stay exactly as I set it?

Yes — pages are copied in the exact order the files appear in the list, so reordering the files before merging is the only thing that controls the final page order.
