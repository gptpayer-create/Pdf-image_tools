How to use Extract Pages

  1. Upload the source PDF.
  2. Type the pages you want to keep, e.g. 1, 3, 5-6.
  3. Tap Run to download a new PDF containing only those pages, in that order.

FAQ

Can I put the pages in a different order than they appear in the original?

Currently pages come out in their original document order regardless of how you list them; for full custom reordering across multiple files, Merge PDF's drag-to-reorder is the better fit.

What if I list a page number that doesn't exist?

Out-of-range numbers are silently ignored, so the tool only pulls the valid pages from your list.
