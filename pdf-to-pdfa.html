FAQ

Is the output guaranteed PDF/A-conformant?

No — true PDF/A conformance also requires things like embedded ICC color profiles and font-embedding checks across the whole file, which this browser-based pass doesn't fully verify. It adds the standard PDF/A identification metadata, which is honest and useful, but not a certified conversion.

What's it good for, then?

It's a lightweight way to flag a PDF's archival intent for systems that check for PDF/A metadata, without needing to install desktop software.

Will this work for strict institutional or legal archiving requirements?

For requirements with strict, audited PDF/A conformance, verify with dedicated archival software; this tool covers the common case of tagging a document for basic archival purposes.

Can I convert several PDFs at once?

Yes — add multiple files and each is tagged independently; you'll get a zip back if you add more than one.
